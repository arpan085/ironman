Under the hood

One camera loop, four honest steps.

No hidden services, no telemetry sent anywhere. The whole pipeline runs in a single process, frame by frame.

01

Capture

OpenCV reads and mirrors each frame from your webcam.

02

Track

MediaPipe's HandLandmarker returns 21 points per hand, handedness-aware.

03

Route

The active mode turns landmarks into an action — draw, click, play a note.

04

Render

A dark HUD shell overlays FPS, mode name, and recording state.

Voice layer

Say the word. Literally.

Toggle the assistant, say "jarvis" plus a command, and it switches modes, sets your volume, starts a recording, or reports FPS back to you — out loud. Offline text-to-speech, no mic hot unless you turn it on.

Get running

Four commands, one webcam.

First launch downloads the hand-tracking model automatically and caches it locally — nothing to configure by hand.

powershell 
# 1. create and activate an environment
> python -m venv .venv
> .venv\Scripts\activate

# 2. install dependencies
> pip install -r requirements.txt

# 3. run it
> python -m gesture_vision.main

# 4. tuned, with the sidebar on
> python -m gesture_vision.main --camera 1 --fps 30 --sidebar
